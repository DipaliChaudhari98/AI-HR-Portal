An AI-Powered Technical Recruitment Assessment Platform built to streamline and automate the end-to-end technical hiring process. The platform enables recruiters to manage job descriptions, generate skill-based assessment questions, shortlist candidates, schedule assessments, and automate candidate evaluations.

It features AI-powered JD parsing and question generation through n8n workflows, candidate self-service slot booking, secure time-bound assessments, automated email notifications, assessment expiration management, and role-based access control (RBAC) for recruiters and administrators.

**Key Features:**
- Automated Job Description (JD) parsing and question generation.
- Bulk job creation through CSV imports.
- AI-powered question bank management.
- Candidate shortlisting and email invitations.
- Self-service assessment slot booking.
- Secure, time-guarded assessment portal.
- Randomized and locked question sets.
- Single-submission enforcement and automated evaluation.
- Automated email reminders and assessment expiration.
- Admin and recruiter management with RBAC.
- JWT-based authentication and secure session handling.

**Tech Stack:**
Next.js, React 19, TypeScript, Tailwind CSS, PostgreSQL, Supabase, Prisma ORM, n8n, Resend API, Docker, Zod, JWT, and REST APIs.

**Goal:** To simplify technical recruitment through intelligent automation, secure assessments, and efficient candidate management.
